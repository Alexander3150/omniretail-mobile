# Modules

Cada modulo representa un dominio funcional customer-facing.

Convencion de crecimiento:

```text
modules/<module>/
  screens/
  components/
  application/
    dto/
    mappers/
    services/
  hooks/
  validation/
  index.ts
```

En esta foundation solo se crean las pantallas placeholder y barrels necesarios. Las carpetas internas se agregaran cuando exista codigo real para alojar.
