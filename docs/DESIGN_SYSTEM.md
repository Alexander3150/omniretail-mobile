# Design System

La foundation incluye tokens minimos en `src/theme`.

## Tokens Iniciales

- `primary`: azul estructural.
- `background`: crema/blanco para superficies base.
- `surface`: blanco para contenedores.
- `text` y `textMuted`: jerarquia de lectura.
- `border`: separadores sutiles.
- `accent`: amarillo suave.
- `success` y `danger`: estados semanticos.

Jimmy controla la direccion UI/UX y reemplazara los placeholders. Esta foundation no define un design system completo ni estilos especificos de FerreHogar.
