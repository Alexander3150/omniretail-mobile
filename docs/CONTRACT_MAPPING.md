# Contract Mapping

Este documento queda preparado para mapear contratos de OmniRetail Web a OmniRetail Mobile sin copiar logica administrativa.

| Dominio mobile | Contrato web origen | Adaptacion mobile | Estado |
| --- | --- | --- | --- |
| Auth | Pendiente | Customer-facing | Pendiente |
| Catalogo | Pendiente | Solo consumo cliente | Pendiente |
| Carrito | Pendiente | Flujo mobile | Pendiente |
| Checkout | Pendiente | Pagos simulados inicialmente | Pendiente |
| Pedidos | Pendiente | Historial y detalle cliente | Pendiente |
| Cuenta | Pendiente | Perfil/direcciones/soporte | Pendiente |

Los contratos se definiran en `src/core/repositories` y sus implementaciones viviran en `src/infrastructure`.
